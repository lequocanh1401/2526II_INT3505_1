# API Design Patterns Exercises (SOA)

Dự án minh họa các mẫu thiết kế API và công nghệ giao tiếp trong môn Kiến trúc hướng dịch vụ.

## Cấu trúc mã nguồn
- `pattern_crud_query_hateoas.py`: Minh họa CRUD, Filtering, Pagination, và HATEOAS.
- `pattern_webhook_server.py` & `pattern_webhook_client.py`: Mô phỏng cơ chế Webhook (Bên gửi và bên nhận).
- `tech_graphql_concept.py`: Mô phỏng tư duy Endpoint duy nhất và chống Over-fetching của GraphQL.

## Cách chạy dự án
1. Cài đặt thư viện: `pip install -r requirements.txt`
2. Chạy từng file bằng lệnh: `python <tên_file>.py`
